2. What is one thing you learned about the codebase or about software engineering practice?

I learned that verifying your local dev environment can reproduce the exact behavior you are trying to change before writing any code is critical. The image insertion issue that blocked my progress was an environment problem, not a code problem. Confirming the baseline behavior works first would have saved time and prevented me from writing plugin code against a broken environment.

3. What is one thing you would do differently?

I would carry my AI chat logs forward between sprints rather than starting fresh. Because I started a new conversation, I had to re-explain the codebase context, the issue specification, and the work already done before Claude could help effectively. Keeping the same session or summarizing the previous sprint's context at the start of a new one would make AI assistance much faster to get up to speed.
